# 面向 AI 服务器脉冲负载的片上 NPU 协同神经扰动预测增强四相交错 Buck 变换器控制方案

本仓库汇集该控制方案的嵌入式工程、PyTorch 神经网络源码、仿真模型、数据集、硬件源文件和项目文档。

## 目录

| 目录 | 内容 |
| --- | --- |
| [`code_ccs/`](code_ccs/) | F28P55 v16 的 MBD/CCS 工程、生成代码、NPU 模型资产、固件与核验记录 |
| [`TCN_PyTorch_Source/`](TCN_PyTorch_Source/) | TCN/ModernTCN 的 PyTorch 源码、训练/预测/评价工具与配置 |
| [`仿真源文件（获取数据集）/`](仿真源文件（获取数据集）/) | 用于生成数据集的仿真源文件 |
| [`数据集/`](数据集/) | 原始交付数据集及配套文件 |
| [`硬件源文件/`](硬件源文件/) | 硬件设计源文件 |
| [`文档/`](文档/) | 项目报告、测试报告等文档 |

## 从哪里开始

- 嵌入式部署与构建：阅读 [`code_ccs/README_交付说明.md`](code_ccs/README_交付说明.md)。
- 神经网络结构、依赖与训练入口：阅读 [`TCN_PyTorch_Source/README_CN.md`](TCN_PyTorch_Source/README_CN.md)。
- 使用工程前，请按各目录说明配置 MATLAB/Simulink、TI 工具链、CCS 或 Python 环境；本机绝对路径需要按实际安装位置调整。

当前神经网络源码包区分 ModernTCN baseline 与面向 TI NPU 的 `ti_npu_fullconv` 网络；模型结构、输入输出及预测步长约定见源码目录说明。

## 文件完整性

首次发布来源为同名桌面交付文件夹，共 17,745 个文件，约 2.58 GB（十进制），按原目录结构导入。

本次发布仅整理并上传交付文件，未重新执行硬件带载实验、仿真或模型训练。工程构建及已有验证结论请以各目录的说明和核验记录为准。
